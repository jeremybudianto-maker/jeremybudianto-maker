# Jeremy Budianto

I turn ideas into interactive web experiences, using Codex to help develop and refine the implementation.

My contribution starts with the concept: understanding the experience I want to create, learning from websites, and shaping the product and visual direction. My projects explore clearer university information, student-service workflows, interactive storytelling, and browser games.

## Selected work

- **IBSC Website Redesign** — a university information redesign with structured content, search, and course browsing. Source is kept private for university prototype review.
- **YZU Connect** — a student-portal concept that explores course selection, service requests, and clearer ownership across offices. It uses fictional demonstration records.
- **PIPE INC — The Next Page Project** — an interactive, chapter-based presentation introducing Taiwanese comics.
- **[DinoStrike](https://github.com/jeremybudianto-maker/Dino-Strike)** — a browser-game prototype with dinosaur teams, equipment, battle interactions, and progression. Cloud and multiplayer features remain under review.

## What I’m learning through these projects

HTML, CSS, JavaScript, Python-based static-site generation, browser state, Canvas animation, interface design, Git, and GitHub. I’m learning these through AI-assisted projects and documenting what each implementation does.

## How I build

I provide ideas, references, and decisions about what should be built. Codex helps generate and revise the code. Each project README explains the actual implementation, the assistance used, the checks performed, and the work that remains.
